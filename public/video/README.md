# Intro-Video

Lege hier `intro.mp4` ab (wird automatisch erzeugt, wenn ffmpeg installiert ist).

```bash
npm run video:intro
```

**ffmpeg installieren (Windows):** [https://ffmpeg.org/download.html](https://ffmpeg.org/download.html)  
oder: `winget install Gyan.FFmpeg`

Ohne ffmpeg spielt das Spiel die **eingebaute Kino-Intro-Sequenz** (deutsch).
